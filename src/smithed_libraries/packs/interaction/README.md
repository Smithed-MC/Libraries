# Interaction

This library serves to enable easier usage of interaction entities as well as enabling custom addons to this usage.

## Usage
[Documentation](https://docs.smithed.dev/libraries/interaction/)
## Downloading
You can download it from [here](https://smithed.net/packs/interaction)
or<br/>
You can build it from source using [beet](https://github.com/mcbeet/beet)

### Building
```
$ pip install beet mecha
$ git clone https://github.com/Smithed-MC/Libraries
$ cd Libraries/interaction
$ beet -s 'meta.libraries = ["interaction"]'
```
